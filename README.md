# Tony Weckström - Sertifikaatit ja badget

Kooste suoritetuista Anthropic Academy -kursseista, muista sertifikaateista ja Google Cloud Skills -badgeista. Kunkin kurssin kohdalla lyhyt kuvaus siitä mitä se kattoi ja miksi se on osaamisen kannalta relevantti.

## Anthropic Academy

**Claude 101** - certificate-a698esz4y628-1783322215.pdf
Peruskurssi Claude-mallien käyttöön: promptaus, mallin rajoitukset ja turvallinen/vastuullinen käyttö. Pohjatieto kaikelle myöhemmälle.

**Claude Platform 101** - certificate-brd8xfefhvpg-1783330182.pdf
Developer-tason yleiskatsaus: API, tool use, MCP ja managed agentit tiiviissä paketissa.

**Introduction to Claude Cowork** - certificate-qa9hvncv7yzr-1783338481.pdf
Cowork-tilan käyttö: tiedostojen ja tehtävien hallinta, automatisointi Clauden avulla ilman koodia.

**Claude with the Anthropic API** - certificate-ttn3zdsszti2-1785260188.pdf
Laaja syväsukellus Messages API:iin: tool use, RAG, extended thinking, vision, PDF-käsittely, citations, prompt caching, MCP ja agenttien rakentaminen. Tämän kurssin pohjalta rakennettu suuri osa omista harjoitusprojekteistani.

**Introduction to Model Context Protocol** - certificate-dd3ydq6v6tu2-1785308077.pdf
MCP-protokollan perusteet: clientit ja serverit, tools/resources/prompts-primitiivit, miten Claude yhdistetään ulkoisiin datalähteisiin standardoidusti.

**Model Context Protocol: Advanced Topics** - certificate-uxxv6yoma875-1785386953.pdf
Jatkokurssi MCP:hen: sampling, roots, progress-ilmoitukset, HTTP- ja stdio-kuljetustavat tuotantokäyttöön.

**Claude Code 101** - certificate-qpgvdgqyphuj-1785671624.pdf
Claude Code -komentorivityökalun peruskäyttö agenttipohjaiseen koodaukseen.

**Claude Code in Action** - certificate-sab7dhkry7vw-1783434409.pdf
Jatkokurssi: pidempien, vähemmän valvottujen ja tiimitasoisten työnkulkujen rakentaminen Claude Codella.

**Introduction to agent skills** - certificate-5obtnbxsoqhy-1783423392.pdf
Agent Skills -ominaisuuden käyttö: uudelleenkäytettävien, paketoitujen taitojen rakentaminen Claudelle.

**AI Fluency: Framework and Foundations** - certificate-vv8nocwrz93u-1783358573.pdf
4D-viitekehys (Delegation, Description, Discernment, Diligence) tekoälyn tehokkaaseen ja vastuulliseen käyttöön.

**AI Fluency for educators** - certificate-7rs68s993vda-1785315835.pdf
4D-viitekehys sovellettuna opettajan/kouluttajan työhön.

**AI Fluency for students** - certificate-6s7sc5q2mceb-1785322243.pdf
4D-viitekehys sovellettuna opiskeluun - painottaa oppimista, ei vain tuottavuutta.

**Teaching the AI Fluency Framework** - certificate-5c7464qjx8xi-1785828670.pdf
4D-viitekehyksen opettaminen muille: miten rakentaa oppitunteja ja arviointeja Delegation-Diligence- ja Description-Discernment-silmukoiden ympärille, ja miten eri kohderyhmille (opiskelijat, kollegat) räätälöidään lähestymistapa.

**Claude on Google Cloud** - certificate-yks5obk38vmp-1785750298.pdf
Sama Claude API -sisältö Google Cloud Vertex AI -alustan kautta. Osoittaa että Claude-osaaminen siirtyy alustalta toiselle (suora SDK, AWS Bedrock, Google Vertex AI) pienin muutoksin.
